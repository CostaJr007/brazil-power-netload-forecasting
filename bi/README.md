# Power BI dashboard

Power BI project **as code** (PBIP + TMDL). The semantic model (12 tables, 18 relationships, 53 DAX measures)
and the **5 report pages (50 visuals)** are generated by script and versioned in git:
`scripts/gerar_projeto_bi.py` (model) and `scripts/relatorio_bi.py` (pages and theme).

## Open it

```powershell
.\.venv\Scripts\python.exe scripts/prever_carga_liquida.py      # (optional) today's forecast with 80% band
.\.venv\Scripts\python.exe scripts/exportar_bi.py               # star-schema tables in data/bi/*.parquet
.\.venv\Scripts\python.exe scripts/gerar_projeto_bi.py          # TMDL model in bi/ (--relatorio regenerates the pages)
```

1. Open `bi/Energia.pbip` in Power BI Desktop and click **Home → Refresh**.
2. If your data lives elsewhere: **Transform data → Edit parameters → PastaDados** (end the path with `\`).
3. Save with **Ctrl+S**: Desktop writes the pages to `bi/Energia.Report/`, so formatting tweaks are versioned too.
   `--relatorio` regenerates the pages in PBIR format (one JSON file per visual) and overwrites Desktop edits, so use it only to start over.

## Star schema

```
dim_date ──────┬─ fact_net_load        hourly backtest D+1/D+2: forecast, actual, benchmark, ONS, 80% band
dim_hour ──────┼─ fact_components      same, per component (load, wind, solar)
dim_subsystem ─┼─ fact_forecast        operational forecast per decision date, with band
               ├─ fact_audit           replay of the audited week
               ├─ fact_price_daily / fact_storage_daily   per subsystem
               └─ fact_system_daily / fact_inflow_basin   national / per basin (date only)
```

The hourly tables hold the 4 subsystems **and** the national total (SIN). Pages filter on SIN by default;
always keep a subsystem filter, otherwise averages mix regions and the total.

## Design

- **Consulting-style layout:** a small purple kicker, an **action title** that states the conclusion (a dynamic
  DAX measure that reads *"Model error is X% lower than the benchmark, beating it on Y% of days"* and updates with the filters), KPI cards,
  two to four charts and a source footnote.
- **Colour with a job:** purple = model, grey = benchmark, light purple = prediction band (custom theme
  `ConsultingPurple.json`). Brand-neutral: no third-party logos or names.
- **Measures, not summed columns:** `discourageImplicitMeasures` forces measures, so an error metric can never be
  summed by mistake.

## Pages

| Page | What it answers |
|---|---|
| **Forecast** | What net load should we expect tomorrow, hour by hour, and how uncertain is it? |
| **Model vs ONS** | Does the model beat the grid operator? By month, by hour, by day type, and its bias over time |
| **Error drivers** | Which component (load, wind, solar) and which region the error comes from |
| **Live audit** | How the forecasts issued at 10 pm the day before did in the audited week |
| **System & price** | Generation mix, reservoir storage, inflows and the estimated spot price |
